# Proyecto Base: Servidor Spring Boot

Este repositorio contiene la estructura base para un proyecto de desarrollo completo. El núcleo principal de la aplicación es un backend robusto construido con **Spring Boot**, el cual sirve como API central.

## 🖥️ Arquitectura del Frontend

Para facilitar la flexibilidad en el desarrollo de la interfaz de usuario, este repositorio cuenta con dos alternativas de Frontend alojadas en ramas independientes:

*   **Rama `angular`**: Contiene la aplicación cliente desarrollada con el framework **Angular**.
*   **Rama `react`**: Contiene la aplicación cliente desarrollada con la biblioteca **React**.

---

## 🛠️ Cómo Empezar

### 1. Clonar el Repositorio
Para descargar el proyecto completo en tu máquina local, ejecuta:
```bash
git clone https://github.com
```

### 2. Cambiar de Frontend
El backend de Spring Boot está disponible en todas las ramas. Para trabajar con el frontend de tu preferencia, simplemente cambia a la rama correspondiente:

*   **Para usar Angular:**
    ```bash
    git checkout frontend-angular
    ```
*   **Para usar React:**
    ```bash
    git checkout frontend-react
    ```

---
💡 *Nota: Asegúrate de revisar el archivo README específico dentro de cada rama para conocer las instrucciones de instalación y despliegue de cada frontend.*
